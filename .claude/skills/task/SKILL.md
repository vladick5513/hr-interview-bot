Описание: $ARGUMENTS

1. Запусти агента `spec-writer` с этим описанием дословно и дождись результата. Проект сам не читай.
2. Если он вернул `ВОПРОСЫ`, задай их человеку, затем передай ответы тому же агенту через `SendMessage`.
3. Покажи человеку результат без изменений в блоке кода, чтобы его можно было скопировать.
4. Спроси, запускать ли цикл. Запускай `/agent-cycle` только после явного подтверждения. Если человек просит правки, передай их тому же агенту.
