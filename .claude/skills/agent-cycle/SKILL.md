Задача: $ARGUMENTS

Ты оркестратор. Код не пишешь и проект целиком не читаешь. Основание «готово» — код выхода gate и вердикт ревью, а не слова агента. Агентам передавай пути и короткие задания, без пересказа. Merge не делай.

Режим `full` включается только словом `full` в задаче. Добавляет агента `tester` для денег, прав доступа, данных и миграций.

Gate, Python и Ruff бери из `.venv` основной папки:

```bash
ruff check app tests && ruff format --check app tests && python -m pytest -q
```

Остановись и спроси человека, если:
- задача неоднозначна и от ответа зависит поведение;
- нужно больше 7 критериев или изменение явно большое: предложи разбить на части;
- базовая ветка не проходит gate;
- после круга исправлений остаётся `blocker` или `major`.

## Шаги

1. Выполни `git fetch origin` и создай worktree:
   ```bash
   git worktree add .agent-cycle/<slug>/wt -b agent/<slug> origin/main
   ```
   Изменения основной папки не трогай.
2. Запиши в `.agent-cycle/<slug>/task.md` задачу, проверяемые критерии и список нужных файлов. Файлы найди через Grep и Glob, не читая проект.
3. Запусти `developer` с путями к worktree и `task.md` и gate. Сам выполни gate, при падении отправь вывод тому же агенту через `SendMessage`. Сделай коммит только файлов задачи.
4. Сохрани `git diff origin/main...HEAD` в `.agent-cycle/<slug>/diff.patch`.
5. Только в `full`: запусти `tester` с worktree, `task.md` и `diff.patch`. Ошибки приложения передай тому же `developer` через `SendMessage`, выполни gate, сделай коммит и обнови `diff.patch`.
6. Запусти `reviewer` с `task.md`, `diff.patch` и worktree. Если `CHANGES`, передай замечания тому же `developer`, выполни gate, сделай коммит. Новое ревью проводится только один раз и только по новому diff.
7. Запиши `.agent-cycle/<slug>/report.md` до 20 строк: критерии и чем проверены, результат gate, ревью, что не проверено. Если менялась схема, проверь миграции на PostgreSQL.
8. Покажи отчёт и попроси подтвердить публикацию. После подтверждения выполни `git push -u origin agent/<slug>` и дай ссылку на PR. Worktree удаляй только после merge.
